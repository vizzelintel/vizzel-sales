# Prompt สำหรับ Claude for browser — Lark Bitable (คอลัมน์นัด 1–10 + UI)

คัดลอกทั้งบล็อกไปวางใน Claude for browser

```
ช่วยตั้งค่า Lark Bitable Vizzel Sales ให้ Support จัดการนัดหมายได้ง่าย
ระบบรองรับสูงสุด 10 ครั้งต่อประเภท (Present / Demo / Site Survey)
แต่ละครั้งมีคอลัมน์แยก — แก้ครั้งที่ N ใน Lark = ครั้งที่ N ในแอป

## สร้างคอลัมน์ใหม่ (ชื่อต้องตรงตัวอักษร)

### Present (พรีเซ็น) — ชุดละ 4 คอลัมน์ × 10 ครั้ง
สำหรับ N = 1 ถึง 10 สร้าง:
| ชื่อคอลัมน์ | ประเภท | หมายเหตุ |
|-------------|--------|----------|
| วันพรีเซ็น N | Date (มีเวลา) | วันเวลานัด |
| Meet พรีเซ็น N | URL | ลิงก์ Google Meet (online) |
| หมายเหตุ พรีเซ็น N | Long text | |
| รูปแบบ พรีเซ็น N | Single select | ค่า: online, onsite |

(N=1 ยังใช้ชื่อเก่าได้: วันพรีเซ็น, ลิงก์ Google Meet, หมายเหตุ Present, รูปแบบ Present)

### Demo — ชุดละ 2 คอลัมน์ × 10 ครั้ง
| วัน Demo N | Date |
| หมายเหตุ Demo N | Long text |

### Site Survey — ชุดละ 2 คอลัมน์ × 10 ครั้ง
| วัน Site Survey N | Date |
| หมายเหตุ Site Survey N | Long text |

### อ่านอย่างเดียว (มีอยู่แล้วหรือสร้างเพิ่ม)
| สรุปนัดหมาย | Long text | แอป generate — อย่าแก้ |
| วิธีใช้ (Support) | Long text | แอป sync คำแนะนำ — อย่าแก้ |

## จัด Layout ใน Lark
1. จัดกลุ่มฟิลด์ตามประเภท: Present 1–10 | Demo 1–10 | Survey 1–10
2. Pin: ชื่อหน่วยงาน, สถานะ, วันพรีเซ็น 1, Meet พรีเซ็น 1
3. Conditional format (สีส้ม): รูปแบบ พรีเซ็น N = online และ Meet พรีเซ็น N ว่าง
4. Filter บันทึก: "รอ Meet" = online + Meet ว่าง (ครั้งใดก็ได้ 1–10)
5. Automation (ถ้าทำได้): แจ้งกลุ่ม Support เมื่อ Meet พรีเซ็น N ว่างหลังตั้ง online

## Workflow Support
- **เพิ่มนัดครั้งที่ 1:** กรอก วันพรีเซ็น 1 + รูปแบบ + Meet (ถ้า online)
- **เพิ่มนัดครั้งที่ 2–10:** กรอกชุดคอลัมน์ N ที่ตรงกับลำดับในแอป (ดู「สรุปนัดหมาย」)
- **แก้ลิงก์ Meet ครั้งที่ 3:** แก้เฉพาะ Meet พรีเซ็น 3 — ไม่กระทบครั้งอื่น
- **ลบนัด:** ล้าง วันพรีเซ็น N แล้วบันทึก
- **อย่าแก้** สรุปนัดหมาย / วิธีใช้ (Support)

## หลังสร้างคอลัมน์
- Admin รัน sync Lark ครั้งหนึ่ง หรือแก้โครงการในแอปเพื่อ push ค่าเข้าคอลัมน์ใหม่
- ทดสอบ: ใส่ Meet พรีเซ็น 2 → เปิดแอปแท็บนัดหมาย ครั้งที่ 2 ต้องมีลิงก์

## ห้ามทำ
- เปลี่ยนชื่อคอลัมน์ core (Project ID, สถานะ, ชื่อหน่วยงาน)
- เพิ่มสถานะ Present ใน dropdown สถานะหลัก
```
