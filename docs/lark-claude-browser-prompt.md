# Prompt สำหรับ Claude for browser — Lark Bitable (งานที่ทำใน Lark UI)

คัดลอกทั้งบล็อกด้านล่างไปวางใน Claude for browser ขณะเปิดตาราง Vizzel Sales Bitable

---

```
คุณช่วยตั้งค่า Lark Bitable (Vizzel Sales) ส่วนที่ทำได้ใน UI เท่านั้น
โครงสร้างคอลัมน์หลักทำเสร็จแล้ว รวมถึง "ลิงก์ Google Meet" (URL) แล้ว

## บริบทสำคัญ (1 โครงการ = 1 แถว)
- ในแอป: นัดได้สูงสุด **10 ครั้งต่อประเภท** (Present / Demo / Site Survey)
- ใน Lark แถวเดียวต่อโครงการ:
  - คอลัมน์ **วันที่** (วันพรีเซ็น, วัน Demo, วัน Site Survey) = **นัดล่าสุด** ของประเภทนั้น — Support แก้ได้
  - **ลิงก์ Google Meet** = Meet ของ **Present ล่าสุด (online)** — Support วางลิงก์ที่นี่
  - **สรุปนัดหมาย** = รายการครบทุกครั้งจากแอป — **อ่านอย่างเดียว ห้ามแก้มือ**
  - **วิธีใช้ (Support)** = คำแนะนำ (แอป sync มา) — อ่านอย่างเดียว

## งานที่ต้องทำใน Lark UI

### 1) เพิ่มคอลัมน์ (ถ้ายังไม่มี)
- ชื่อ: **วิธีใช้ (Support)**
- ประเภท: **ข้อความยาว (Long text)**
- วาง: หลัง **สรุปนัดหมาย** หรือก่อน **เอกสาร**
- คำอธิบายฟิลด์: "คำแนะนำการใช้งาน — อัปเดตจากแอป อย่าแก้"

### 2) Pin คอลัมน์ (ตรึง)
Right-click หัวคอลัมน์ → ตรึง:
1. ชื่อหน่วยงาน
2. สถานะ
3. วันพรีเซ็น
4. ลิงก์ Google Meet

### 3) Conditional format (ไฮไลต์งานรอ Meet)
สร้างกฎสีแถวหรือเซลล์ (สีส้มอ่อน #FFF3E0):
- เมื่อ **รูปแบบ Present** = `online`
- และ **ลิงก์ Google Meet** ว่าง (empty)

เป้าหมาย: Support เห็นทันทีว่าต้องสร้าง Meet แล้ววางลิงก์

### 4) Automation — แจ้งเตือน Support (ถ้าทำได้)
เปิด **ระบบอัตโนมัติ** → Rule ใหม่:
- Trigger: เมื่อบันทึกแถว และ **รูปแบบ Present** = online และ **ลิงก์ Google Meet** ว่าง
- Action: ส่งข้อความในกลุ่ม Support / comment ใน record
- ข้อความตัวอย่าง: "รอลิงก์ Meet — {ชื่อหน่วยงาน} — วันพรีเซ็น {วันพรีเซ็น}"

### 5) จัด View ให้ Support ใช้งานง่าย

**Grid (มุมมองหลัก)**
- ซ่อนคอลัมน์ที่ไม่จำเป็นบ่อย (เช่น อัปเดตล่าสุด, Project ID) — ไม่ลบ
- เรียงคอลัมน์กลุ่ม: ข้อมูลโครงการ | Present+Meet | Demo | Survey | สรุป+วิธีใช้ | เอกสาร

**Kanban (ถ้ามี)**
- Group by: **สถานะ**
- Card แสดง: ชื่อหน่วยงาน, บริษัท Dealer, วันพรีเซ็น, ลิงก์ Google Meet

**Filter แนะนำ (บันทึกเป็นมุมมอง)**
- "รอ Meet": Present=online + ลิงก์ Google Meet ว่าง
- "นัดสัปดาห์นี้": วันพรีเซ็น / Demo / Site Survey ภายใน 7 วัน

### 6) คำอธิบายหัวคอลัมน์ (Field description) — ใส่ใน Lark
| คอลัมน์ | คำอธิบาย |
|---------|----------|
| วันพรีเซ็น | นัด Present **ล่าสุด** — แก้ได้ |
| ลิงก์ Google Meet | Meet ของ Present ล่าสุด (online) — วางลิงก์แล้ว sync เข้าแอป |
| สรุปนัดหมาย | ประวัติครบจากแอป (สูงสุด 10/ประเภท) — **อย่าแก้** |
| วิธีใช้ (Support) | คู่มือสั้น — **อย่าแก้** |

### 7) สิ่งที่ห้ามทำ
- เปลี่ยนชื่อคอลัมน์ core (โดยเฉพาะ ลิงก์ Google Meet, รูปแบบ Present, วันพรีเซ็น)
- แก้ **สรุปนัดหมาย** หรือ **วิธีใช้ (Support)** ด้วยมือ
- เพิ่มสถานะ "Present" ใน dropdown สถานะ

## Workflow Support (จำง่าย)
1. **ดูภาพรวม** → เปิดแถว → อ่าน **สรุปนัดหมาย** (ครั้งที่ 1–10)
2. **แก้นัดล่าสุด** → แก้ วันพรีเซ็น / หมายเหตุ Present / รูปแบบ Present
3. **ใส่ Meet** → วาง URL ใน **ลิงก์ Google Meet** → บันทึก → รอ ~1 นาที → dealer เห็นในแอป
4. **เพิ่มนัดครั้งที่ 2–10** → ให้ Dealer กดในแอป (ไม่สร้างซ้ำใน Lark ด้วยวันที่คอลัมน์เดียว)

## หลังตั้งค่าเสร็จ
- ทดสอบแถว "การกีฬาแห่งประเทศไทย": ใส่ meet link → ตรวจแอปแท็บนัดหมาย
- ยืนยัน Pin + Filter "รอ Meet" ใช้งานได้
```
